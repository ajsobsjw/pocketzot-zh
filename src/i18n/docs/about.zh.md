# 关于 PocketZot

PocketZot 是一款非官方 [DCSS](https://crawl.develz.org) 客户端，面向竖屏使用的 iOS 和 Android 手机。你可以连接 [WebTiles](https://crawl.develz.org/wordpress/howto) 服务器在线游玩，也可以直接在设备上离线运行 DCSS。

## 入门指南

DCSS 没有 App Store 应用，也不需要从商店下载。在 iOS 分享菜单或 Android 浏览器菜单中选择「添加到主屏幕」，就能像应用一样安装 PocketZot。之后可以登录 WebTiles 服务器，也可以离线游玩。iPad 和其他平板同样支持。

## 功能

- 通过 WebTiles 服务器在线游玩
- 在设备上离线游玩
- 支持 ASCII 和图块地图
- 随游戏菜单变化的操作按钮
- 可自定义的触控操作
- 地图手势
- 可直接点按多种菜单和说明中的选项
- 可折叠的浮动怪物列表，点按即可查看怪物
- 使用扩展地图视野的观战模式
- 聊天
- 8.6 万亿种标志图案

## 操作

操作按钮分为 **@**、**>** 和 **?** 三个标签页。

- **@** 用于战斗等需要随时进行的操作。
- **>** 用于非战斗时或清理完一层后常用的操作。
- **?** 用于查询角色和游戏信息。

也可以使用屏幕键盘。

## 手势

- 点按浮动怪物列表可查看怪物。
- 把浮动怪物列表滑到另一侧，或拖动它查看后方的内容。
- 点按状态栏中的地名（如 `@D:1`）可开关小地图。
- 长按地图格子可查看该处的内容。
- 长按法术并拖动，可调整快捷施法栏的顺序。
- 瞄准或查看（`x`）时，点按或拖动地图可移动光标。
- 拖动地图可打开本层地图（`X`）。
- 双击地图可切换缩放级别。
- 双指长按地图可切换 ASCII 和图块。
- 按住方向键可按住 Shift 移动。
- 双击 Shift 可锁定它。

### 本层地图（`X`）

- 拖动地图可平移视野。
- 点按或拖动小地图也可平移视野。
- 点按地图可放置光标。

## 离线游玩

点按登录界面上的「离线游戏」，即可在设备上运行 DCSS，无需服务器或账号。首次启动需联网下载引擎和图块数据，之后即使在飞行模式下也可以游玩。

离线角色使用具名存档位。你可以浏览过往游戏的分数和角色记录、编辑选项（RC）文件，或用「备份」把数据导出为单个文件，留存或迁移到另一台设备。存档保存在当前设备上，建议定期导出备份。

## 版本支持

支持当前稳定版和开发版（trunk）。一般可兼容到 0.24，能否运行更早的版本或其他分支取决于具体版本。0.24 以前的版本无法新建角色。当前离线版随附 0.35-a0。

## 安全与隐私

PocketZot 不提供独立账号。和桌面 WebTiles 客户端一样，浏览器通过加密的 WebSocket 直接连接你所选的 DCSS 服务器。登录凭据只随登录消息发送，应用不会保存密码。「本机已保存」保存的是服务器会话 Cookie。站点记录匿名使用次数。
